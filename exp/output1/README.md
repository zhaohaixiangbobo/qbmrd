## How to use

Read the data index for the relevant analysis. For public month-level statistical verification, follow the code guide from this repository root. Empirical optimization requires authorised enterprise inputs supplied separately through confidential review access.

Historical supporting records remain in the supplementary-data directory. The independent 36-run verification performed on 16 October 2026 is separately labelled under Verification/D3_20261016. Its public scalar records and comparisons do not replace the historical results. Complete configurations, internal-attempt traces and allocation matrices are supplied to reviewers in the separate confidential R3_D3_Verification_20261016_Review_Only.zip Related file.

## Access and submission

Public derived records and selected implementation files are provided here. Authentic English deidentified enterprise input/reference data and confidential detailed allocation workbooks are available to editors and referees through the separate Related-file review package. Source inputs and confidential allocations are not included here.

Upload this directory's contents to the intended repository. A live repository URL should be added to the submission only after upload and access verification. This local preparation does not establish a public URL or complete submission-system fields. Licensing is stated explicitly below.
